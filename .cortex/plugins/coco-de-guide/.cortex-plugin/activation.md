This plugin supports data engineering workflows for the TPCH demo project on Snowflake.

It includes:

- **Skills**: `new-dbt-model` — guides the creation of new dbt models with source references and schema tests.
- **Agents**: Subagents for specialized tasks (defined in the `agents/` directory).
- **Hooks**: Pre/post tool hooks for workflow automation (defined in `hooks/hooks.json`).
